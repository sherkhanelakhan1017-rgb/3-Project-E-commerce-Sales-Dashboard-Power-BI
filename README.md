 E-commerce Sales Dashboard – Power BI
An interactive Power BI dashboard project focused on analyzing e-commerce sales performance, customer behavior, regional insights, profit trends, and payment preferences.

This project was built using Power BI to transform raw sales data into meaningful business insights through interactive visualizations and KPI reporting.


🔹 Key Features
✅ Interactive KPI Cards
✅ Monthly Sales & Profit Trend Analysis
✅ State-wise Sales Performance
✅ Category-wise Quantity Analysis
✅ Payment Mode Insights
✅ Top 5 Customers Analysis
✅ Dynamic Filters & Slicers
✅ Business Intelligence Dashboarding


🔹 Tools & Technologies Used
Power BI
Power Query
DAX
Data Modeling
CSV Data Sources
Data Visualization

🔹 Key Business Insights
📌 Maharashtra generated the highest sales revenue
📌 COD emerged as the most preferred payment mode
📌 Clothing category contributed the highest quantity sold
📌 Monthly sales trends highlighted seasonal fluctuations in business performance
📌 Top customers contributed significantly to overall revenue
